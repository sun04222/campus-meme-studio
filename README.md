# 校园表情包工坊 · 30 秒出一张表情包

选底板、敲文案、导出符合征集要求的 JPEG 表情包。一个纯前端单页工具：**零依赖、零构建、零后端、零外部素材** —— 双击 `index.html` 即可用。

- 全部内容在一个 `index.html` 里：内联 CSS + 原生 JS + Canvas 2D，无框架、无 npm、无构建步骤、无网络请求
- 6 款底板与所有文案由 Canvas 代码绘制，**不含任何外部图片素材**，无版权顾虑
- 导出 600×600 JPEG（质量 0.92），通常 20–60 KB；征集上限 10MB，导出前自带体积守卫

## 快速开始

双击 `index.html`（或拖进浏览器）→ 左侧选底板 → 敲文案 → 点「导出 JPEG」，文件名 `pack_01.jpg`，点「连做下一张」继续编号。快捷键 `Ctrl/Cmd + S` 直接导出。

## 为什么做这个

「网创梦工厂」征集里，表情包是最低门槛的形态：一句话 + 一张底图就是一件作品。
但不会画画的人卡在"做不出图"。这个工具把这件事降到 30 秒：
选底 → 打字 → 导出。

## 用法

1. 双击打开 `index.html`（或拖进浏览器）。
2. 左侧选一张底板（6 款，全部由 Canvas 代码绘制）。
3. 输入主文案 / 副文案（各限 40 字，超长自动折行）。
4. 调字号、颜色、垂直位置、描边。
5. 点「导出 JPEG」下载 `pack_01.jpg`；点「连做下一张」继续，编号自动递增。

快捷键：`Ctrl/Cmd + S` 直接导出。

## 功能

| 功能 | 说明 |
| --- | --- |
| 底板 | 早八橙 / 深夜蓝 / 薄荷绿 / 草稿纸 / 水墨黑 / 糖果粉 |

| 连续出图 | `pack_01.jpg`、`pack_02.jpg`… 凑一套九宫格 |

## 刻意不做

- **GIF / 动图**：浏览器原生导不出 GIF，需引库或手写 LZW 编码，成本远超收益。
- **上传图片做底图**：会引入裁剪、比例、Canvas 跨域导出污染等大量边界问题。
- **在线素材库 / 贴纸**：版权与资源托管都是无底洞。
- **手绘 / 笔刷 / 图层**：那是绘图软件，不是本项目目标。
- **后端 / 账号 / 作品管理 / 一键投稿**：会把工具变成平台。
- **框架、打包、测试、多语言**：单页静态足够。
